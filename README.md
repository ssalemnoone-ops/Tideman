# Tideman

A C implementation of the **Tideman ranked-choice voting system**.

## Requirements

* GCC
* CS50 Library

## Compile

```bash
gcc-16 tideman.c -I/usr/local/include -L/usr/local/lib -lcs50 -o tideman_program
```

## Run

```bash
./tideman_program
```

## Files

* `tideman.c` — Main C source code for the Tideman program.
